# OD 数据与多空间轴评估

本批为 GEML、CSTN 的原生迁移补齐公共数据能力，不将两个模型提前登记为已支持。当前模型迁移计数仍为 70/100；排除延期 Common 和模板后，还有 21 个实际模型待迁移。

## 原问题

- 普通交通数据以节点为唯一空间轴，不能直接表达起点、终点均有独立节点身份的 OD 流量。
- 公共指标只接受 `[B,H,N,C]`，无法直接对 OD 的 `[B,H,N,N,C]` 或网格 OD 的多个空间轴正确聚合。
- 来源版本清单未包含 `.od`、`.gridod`。原始文件变化时必须阻止不一致的完整续训。
- 基于归一化流量的正值判定会改变真实零流量的含义；天气等未知未来观测也不能随预测目标进入模型。

## 实现

新增 `libcity.data.od_bundle.prepare_od(data, training, evaluation, seed, logger=None)`，各参数沿用公共运行时的对应配置区块。组件要求 `data.sampling.name=od_window`，供后续模型的 `prepare_data` 接口调用。当前未增加 GEML/CSTN 的模型注册或可运行 CLI 预设，不能把普通 GRU 配置改名后当作 OD 模型运行。

数据文件支持 `.od`、`.gridod`，以及包含 OD 标识列的 `.dyna`，按这个顺序查找。数据列由元信息 `data_col` 指定，未声明时从非保留列推断；目标为前 `output_dim` 个观测列。

- `.geo` 行序确定两个空间轴的节点顺序，实际 ID 可不连续。CSV 数据行可乱序。
- 每个时间点、起点、终点必须恰好一行；零流量需显式编码，拒绝重复、缺行、未知节点及无穷值。
- 网格坐标通过 `.geo` 的 `row_id/column_id` 映射到真实节点；要求完整矩形。统一输出仍保留起点、终点两轴，网格形状及逐节点位置保存在只读元信息中，供模型恢复网格布局。
- `.rel` 使用真实节点 ID，保留有向原始权重或显式二值图；对称化、自环由配置决定。允许没有关系文件，拒绝重复关系、负权及非有限权重。

批次是标准 Tensor 字典：

| 字段 | 未组批形状 | 含义 |
| --- | --- | --- |
| `X` | `[Tin,N,N,F]` | 历史观测；缺失值用原尺度零补入，目标列按训练统计归一化 |
| `history_mask` | `[Tin,N,N,F]` | 原始历史中有限且严格大于零的位置，布尔类型，不从归一化值推断 |
| `y` / `y_raw` | `[H,N,N,C]` | 归一化目标 / 未修改的原尺度目标，后者保留零与 NaN |
| `history_features` | `[Tin,E]` | 可选的历史全局日历和外部协变量 |
| `future_features` | `[H,K]` | 可选的日历及明确声明为已知未来的外部列 |

流量特征不混入日历和全局天气。`known_future_columns` 只能选择已加载的 `.ext` 列；其他外部观测只提供历史值。公共 `model_inputs` 显式传递历史掩码，继续过滤 `y/y_raw`。

按原始时间轴先确定训练、验证、测试边界，再选取目标窗口完全位于对应区间的样本。历史可使用切分点之前的已知观测，但完整输入及目标窗口不能跨文件边界或实际时钟缺口。归一化器仅在原始训练区间拟合。只允许按配置填充训练尾批，验证和测试保留真实样本数。

缓存只保存未展开的原始观测、外部特征、时钟、文件区间和图，不缓存滑窗或拟合后的归一化器；窗口、切分、scaler 和批次变化可复用原始数组。缓存验证形状、数值类型、时钟、文件区间和有限性，损坏时重建。来源判定使用路径、大小和修改时间，不对源文件内容做哈希；完整续训的来源版本检查现已覆盖 `.od/.gridod`。

`ForecastMetrics` 接受 `[B,H,...,C]`，每个预测步归约批次与全部空间/特征轴，再跨批次聚合可加统计。`single/average` 两种模式及原有节点预测规则保留；导出的预测仍保存原始空间轴，不把 OD 空间结构压成节点编号。

## 验证范围

`tests/test_runtime_od_data.py` 共 20 项：三种格式、乱序与非连续 ID、网格映射、真实时间切分、训练区间归一化、零/NaN 历史语义、未来观测隔离、原始缓存跨配置复用及三种损坏重建、多文件和时间缺口、无效稠密行、三种空间布局及两种指标模式。

使用明确命名的测试模型 `ODProbe` 实际运行公共训练、独立评估、OD 预测导出，并逐项核对连续训练与中断恢复后的参数、优化器、调度器、AMP、计数、早停、最佳权重、随机状态和加载器状态。仅修改测试区间的原始 OD 值，保持训练统计及布局不变，验证续训被来源版本检查拒绝。

这个测试模型只证明公共组件能处理 OD，不证明 GEML/CSTN 的网络、辅助损失或论文精度。完整回归结果与本批提交映射见 [主线执行记录](remaining-work_execution_zh.md) 和 [汇总报告](remaining-validation.json)。
