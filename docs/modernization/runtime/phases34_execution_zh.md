## 第一批：预测输入与目标时间轴

- 用目标窗口完整所属的时间区间选择样本；跨训练/验证/测试边界的窗口被丢弃，历史可以使用切分点之前的观测。
- 按原始时间点拟合训练区间归一化器，不用重复滑窗或验证/测试值拟合；支持比例与显式 train_end/val_end 时间边界。
- X 为历史观测；future_features 只含日历和明确声明的已知未来外部协变量；y 只含归一化后的目标；y_raw 保留原始目标供指标与掩码使用。训练期 Teacher Forcing 仍显式使用 y。
- GRU 滚动预测对不可提前获取的辅助观测沿用最后历史值，不读取未来观测；Trafformer 时间编码只选择已知特征；公共评估、DCRNN、ASTGNN、MTGNN 均使用原始目标做掩码。
- CRANN 四组输入/标签同步按目标窗口划分，并隔离旧缓存命名。通用适配不再读写旧滑窗展开缓存；cache 参数保留目录配置，深度缓存改造仍在后续事项内。
- 同权重计算对照继续保留；旧 Trafformer 参考测试在测试端重组旧 y 格式，生产入口不恢复对标签的依赖。

验收：tests/test_runtime_timeline.py 覆盖目标时间互斥、历史越界合法、验证集污染不改变训练统计、无标签/标签污染推理、观察量隔离、显式未来协变量、原始零值掩码与 CRANN 四字段对齐。真实 METR-LA 短跑由 tools/validate_runtime_real_data.py 记录。

阶段三完整回归 **190 项通过**，记录见 [phase3-validation.json](phase3-validation.json)。真实 METR-LA 前七天、207 节点、12→12 步 GRU 单轮训练及独立评估一致，记录见 [metr-la-phase3.json](metr-la-phase3.json)；该记录是功能短跑，不是全数据精度基准。

## 第二批：标准训练与其余任务代表组合

- 新增标准 FNN、GWNET；两者没有专用训练函数。FNN 保留原计算，GWNET 将旧 Conv1d/四维张量不匹配改为 Conv2d，将静态支持图注册为 buffer，并取最后时刻输出固定预测窗口。
- 新增 traj_loc_pred/RNN：原子轨迹按目标时刻切分，变长序列打包，整词表排名，按 Recall 最大化挑选最佳模型，导出原 POI ID；padding 不参与候选地点。
- 新增 eta/DeepTTE：路线几何卷积、属性嵌入、RNN、全程及局部估计两个分支。计划路线几何作为已知输入，观测耗时仅作为目标；归一化只使用训练区间，主损失采用统一 MAE/MSE，辅助局部 MAPE 由显式 step 计算。修复旧距离重复归一化、padding attention 和 batch=1 squeeze 问题；不宣称这些有意修订后的结果与旧缺陷计算逐值一致。
- 新增 road_representation/LINE：保留一阶/二阶点积与负采样目标，先切分正边再采样；训练期间不写向量文件，评估阶段统一导出 embeddings.npy 和 node_ids.json。该任务记录验证负采样损失，不声称等价于下游道路分类精度。
- 通过模型注册声明选择数据适配、损失和评估函数，三个任务继续共用 train_loop、优化器、调度、早停、AMP 与安全续训。独立评估不创建训练组件。

本批专项 8 项通过：包含五个新增模型前向/短训练，三个新增任务独立评估、标签隔离和逐参数完整续训；FNN/GWNET 另与修正后的旧计算作相同权重对照。STSSL、统一调参与最终迁移表继续在后续批次完成。

## 第三批：STSSL 跨轮次算法状态

STSSL 使用独立 train 函数，复用公共参数更新、AMP、累积、裁剪、调度、早停和检查点。最近两轮的三项损失、动态权重和轮次写入 TrainState.task_state，完整续训恢复后再计算下一轮权重。推理只运行原图预测，不进行随机增强；辅助训练方法单独返回预测与时空损失。

有意修正旧增强中的边索引错位和 CPU NumPy 操作，动态权重分母增加零值保护；监督损失与公共原始目标掩码统一，不沿用旧代码中写死的 5.001 阈值。当前接入要求 input_window>=9、output_window=1。没有将该模型伪装成任意预测窗支持。

专项验收覆盖 dropout、图/属性随机增强、动态加权第三轮前中断，续训后逐参数、学习率、任务进度与连续训练精确一致；独立推理不消耗随机状态，统一入口能导出并复现最佳权重评估。

## 第四批：统一调参入口

run_hyper.py 变成薄 CLI，调用 pipeline/runtime_tuning.py；网格与固定种子随机搜索使用标准库，未提前选定 Optuna/Ray 等延后讨论的外部后端。搜索空间是点分配置键到有限候选列表的 JSON。

每个 trial 在新目录中重新解析配置、装配数据和模型；包括滑窗、归一化参数变化。run_experiment(evaluate_test=False) 仅训练/验证并返回验证分数与权重，不进入测试评估，不产生 trial 的 eval/ 目录。统一按 monitor 和 min/max 方向挑选验证最佳 trial，随后只对其 best.pt 独立评估一次测试集；身份、运行目录和选模指标不允许在同一搜索中变化。

专项 8 项通过，包括给 test loader 加迭代禁令、四组数据预处理变化、独立 trial 目录、Recall 最大化、固定种子随机搜索、非法空间启动前拒绝以及仓库外目录实际运行 run_hyper.py。旧 Hyperopt/Ray 内部实现保留为阶段五清理对象，新入口不再调用它们。
