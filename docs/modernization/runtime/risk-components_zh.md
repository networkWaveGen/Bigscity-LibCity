# GSNet 的风险数据、损失与评估前置组件

本文记录 commit52 补齐的公共前置组件；当批尚未注册 GSNet 神经模型，迁移计数为 73/100。测试模型 RiskProbe 只验证组件生命周期，不能当作 GSNet 网络或论文精度结果。后续原生网络、正式配置和实际 CLI 已另行接入，最新状态见 [GSNet 迁移说明](gsnet_zh.md)。

## 原问题与实现

旧数据加载把完整网格和图节点混作同一类节点，用 geo_id 的数值直接作为矩阵下标，部分网格覆盖、乱序或非连续 ID 时会错位。未来时间注意力需要预测时刻的已知时间信息，不能从真实风险目标构造。旧事故指标在并列分数时按阈值取全部格子，可能超过 top-k；零事故窗口及跨批次平均也缺少稳定口径。

新增 `prepare_gsnet(data, training, evaluation, seed, logger=None)`：

- `.geo` 描述图节点，要求唯一有限 ID、所属 row_id/column_id 和非负 risk_mask；完整网格大小由数据元信息 grid_len_row/grid_len_column 给出。网格单元采用明确的行优先坐标身份，图节点保留实际 geo_id，二者数量可不同。
- 建立 `[网格数,图节点数]` 的只读映射；同一网格可映射多个图节点，但其 risk_mask 必须一致。不依赖 ID 大小，不把无图节点的格子伪造为图节点。
- `.grid` 或坐标式 `.dyna` 提供完整网格观测；`.rel` 按真实图 ID 读取 road/risk 和可选 poi 列。保留给定有向权重，拒绝重复关系、未知 ID 和非有限权重；图是给定静态先验，本组件不从全时间轴重新估计风险图。
- `risk_cpt` 使用最近帧、日/周周期的明确时间偏移。目标窗口互斥、历史可用切分前观测、scaler 仅拟合原始训练区间，y_raw 保持原始值。
- 时间编码为 24 小时与 7 星期 one-hot，未来向量按真实预测时间生成。只有 known_future_columns 明确声明的外部列或空间恒定的非目标观测列可以进入未来输入；风险目标禁止声明为已知未来。
- 数值全局外部列分别用原始训练区间拟合归一化器；日历 one-hot 和已声明的原始时间标志保持自身含义。这是相对旧混合归一化的明确修订。

批次仍为标准 `X [B,T,N,F]`、历史全局特征、已知未来特征、y/y_raw。metadata.num_nodes 指完整网格数；图节点 ID、图特征选择及单独图节点数显式登记。路图、风险图、可选 POI 图、映射和区域掩码放在只读 static_data 中。

原始时序缓存不存展开窗口或拟合后的外部 scaler。切换窗口、主/外部 scaler、图输入列或是否启用 POI 可复用原始数组，静态图单独按当前配置读取。缓存及续训仍用路径、大小、修改时间检查来源，不对文件内容做哈希。

## 风险加权目标

`RiskLoss(bundle, config)` 要求 `name=risk_mse`、mask_value=null。阈值和权重可由训练 loss 配置给出，未给出时读取数据元信息的 risk_thresholds/risk_weights；它们始终解释为原尺度风险的分档。阈值严格递增，权重非负且至少一项为正；空阈值配单个权重也可运行。

记格子数 N、有效区域数 M、区域权重 r、全网格平均权重 mean(r)、已知有效区域目标集合 V。目标为：

`(M/N) × mean_V[(prediction_raw - target_raw)² × (r/mean(r))² × bin_weight(target_raw)]`

区域归一化因子是平方，保留[原作者损失](https://github.com/Echohhhhhh/GSNet/blob/master/lib/utils.py)及 LibCity 的作用方式。全观测时该式与原来的完整网格平均一致；有缺失值时按有效区域目标数累积，微批和真实尾批得到同一有效批次目标。真实零风险参与分档和训练，全部有效目标未知时返回零权重以跳过更新。风险阈值恰好相等时归入其左侧分档。

## 区域评估与排名

`RiskMetrics` 和 `evaluate_risk` 仅在 risk_mask>0 且目标有限的格子评估；区域权重的幅度仅作用于训练目标，普通误差指标按合格格子计数。预测/原始目标完整导出，额外保存 regions 布尔向量，不篡改原始真值。

- MAE/MSE/RMSE/MAPE/R2/EVAR 复用公共可加统计，支持原有 single/average 预测步口径。
- Precision/Recall/F1-Score/MAP 对每个样本、每个预测时刻独立计算，再按真实帧数聚合。正例为真实风险>0；取恰好 min(topk,合格格子数) 个格子，分数相同时按行优先格子索引排序，避免并列导致选中数量超限。
- MAP 为 AP@K 的逐帧平均，AP 分母为 min(真实正例数,实际候选 K)。零正例或空候选帧返回 0，仍计入平均。
- PCC 为每帧区域 Pearson 相关的平均；常量或不足两个有效格子时为 0。排名和 PCC 的 average 模式对前若干预测时刻的帧分数平均，不把多个时刻混成一个空间排序。

以上口径明确修订了旧批次均值、并列扩张及零事故异常，不据此声称与旧错误评估或论文报告数值相等。

## 验证范围

新增 28 项：部分图节点/完整矩形、非连续乱序 ID、双图/三图及只读映射；真实未来时间、显式已知原始时间列、训练区间外部归一化及未来风险/未知天气隔离；无效数据拒绝；三种 scaler 下原始区域平方权重/阈值边界的独立损失和梯度；空阈值与空有效组；有效数不同的微批梯度；NumPy 独立排名/PCC/区域误差，两个模式及不同 top-k/尾批/并列；缓存跨图选择和 scaler 复用。

RiskProbe 实际运行统一训练、区域评估及原始导出、关闭预测导出、dropout/优化器/调度器/早停/最佳模型/RNG/加载器状态精确续训，并确认静态关系来源变化会拒绝恢复；另有真实 CPU AMP。当批相关网格和 DSAN 合计 108 项通过，完整回归 1150 项通过、无失败/错误/跳过，历史计数见 [报告](remaining-validation.json)。本组件批次不包含 GSNet CLI 验收；后续原生网络和正式配置的实际验收另见 GSNet 迁移说明。
